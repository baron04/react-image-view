有三个问题被反复问到，这里按顺序回答：**怎么改样式**、**怎么替换某一个按钮**、
**怎么加我自己的东西**。每个问题都有一个「改动最小」的答案 ——
大多数情况下你不需要退到完全组合。

## 你到底需要改多少？

| 你想要… | 用什么 | 需要重写界面吗 |
|---|---|---|
| 换颜色、圆角、间距 | [CSS 自定义属性](#1-css-自定义属性) | 不需要 |
| 深度重写某个部件的样式 | [`data-*` 选择器](#2-data-属性) | 不需要 |
| 换掉某个按钮的元素或图标 | [`asChild` / children](#3-aschild) | 不需要 |
| 增加、删除、重排按钮 | [自己组合 `Content`](#4-自己组合-content) | 需要，但用的是同一批部件 |
| 加快捷键或手势规则 | [Extensions](#5-extensions) | 不需要 |
| 翻译界面文案 | [`labels`](#6-labels) | 不需要 |

## 1. CSS 自定义属性

最快的改法。预设样式表里所有取值都来自自定义属性，
覆盖它们就能重新配色，一个选择器都不用写。

```css
:root {
  --riv-accent: #0f766e;          /* 焦点环、控件激活态 */
  --riv-accent-surface: #ccfbf1;  /* 激活控件的背景 */
  --riv-chrome: #ffffff;          /* 顶栏和工具栏的表面色 */
  --riv-stage: #f4f4f5;           /* 图片后面的区域 */
  --riv-ink: #18181b;             /* 主文字与图标 */
  --riv-ink-muted: #71717a;       /* 次级文字 */
  --riv-line: #e4e4e7;            /* 边框与分隔线 */
  --riv-hover: #f4f4f5;           /* 控件 hover 背景 */
  --riv-radius: 12px;             /* 弹窗圆角 */
  --riv-radius-toolbar: 10px;     /* 工具栏圆角 */
}
```

设置在 `:root` 或 dialog 元素上，**不要**设置在某个祖先类上。预览器会 portal 到
`document.body`，作用域限定在包裹类上的规则根本够不着它。
这也是深色模式绑定在 `prefers-color-scheme` 加显式的
`data-riv-theme="light" | "dark"`（写在 `:root` 或 dialog 上）、
而不是绑定在某个容器的 `.dark` 类上的原因。

## 2. data-* 属性

每个部件都会把自己的身份和状态以 `data-*` 暴露出来，
所以你可以用原生 CSS 或 Tailwind 变体直接命中，不需要知道任何类名。

```css
/* 某一个具体控件 */
[data-image-view-control='actual-size'] { font-variant-numeric: tabular-nums; }

/* 是状态，不是类名 */
[data-image-view-control][data-active] { outline: 2px solid var(--riv-accent); }
[data-image-view-control][data-boundary] { opacity: 0.35; }

/* 区域 */
[data-image-view-region='toolbar'] { backdrop-filter: blur(8px); }
[data-image-view-stage][data-phase='dismissing'] { cursor: grabbing; }
```

```tsx
// 同样的钩子在 Tailwind 里
<ImageView.ActualSize className="data-[active]:bg-teal-100 data-[boundary]:opacity-40" />
```

完整清单：`data-image-view`（dialog）、`-stage`、`-viewport`、`-track`、
`-slide`、`-trigger`、`-title`、`-counter`、`-loading`、`-error`、
`-thumbnails`、`-thumb`、`-region="header|toolbar|footer"`，以及
`-control="close|prev|next|zoom-in|zoom-out|rotate-left|rotate-right|fit|actual-size|download|retry"`。
状态：`data-active`、`data-boundary`、`data-disabled`、`data-current`、
`data-phase`、`data-state`、`data-closing`。

## 3. asChild

要换掉控件的**元素本身** —— 比如换成你设计系统里的按钮，或者外面包一层 tooltip ——
传 `asChild` 并把元素交给它。控件会把行为、`aria-label` 和 `data-*`
合并到你的子元素上，而不再渲染自己的 `<button>`。

```tsx
import { Button } from '@/components/ui/button';

<ImageView.ZoomIn asChild>
  <Button variant="ghost" size="icon">
    <PlusIcon />
  </Button>
</ImageView.ZoomIn>
```

只想换**图标或文字**的话，直接传 children，不需要 `asChild`：

```tsx
<ImageView.Close>
  <XIcon /> 收起
</ImageView.Close>
```

<Aside type="caution" title="asChild 的子组件必须转发 props 和 ref">
  控件是通过 Slot 克隆子元素来传递点击处理函数、测量动画用的 ref
  和 `data-*` 的。如果你的子组件把不认识的 props 丢掉了，
  这些东西会被一起吞掉 —— 表现是缩略图渲染正常，但点了没有任何反应，
  而且不会报错。用 `React.forwardRef` 并把 `...rest` 铺到真实 DOM 节点上。
</Aside>

## 4. 自己组合 Content

要增加、删除或重排按钮，就自己写外壳。用的是 `DefaultContent`
所用的同一批部件 —— 它底下没有任何私有实现 —— 所以这么做不会损失什么。

规则是：**如果 `Root` 在子节点里找到了 `<ImageView.Content>`（或 `<DefaultContent>`），
它就什么都不再补。** 否则它会补上默认界面。所以「自己组合」就是把 `Content` 自己写出来。

```tsx
<ImageView.Root images={files}>
  {/* triggers */}

  <ImageView.Content className="riv-dialog">
    <ImageView.Header className="riv-header">
      <ImageView.Close>关闭</ImageView.Close>
      <ImageView.Title />
      <ImageView.Counter />
      <span className="flex-1" />
      {/* 你自己的按钮，就放在内置控件旁边 */}
      <button onClick={() => print()}>打印</button>
      <ImageView.Download>下载</ImageView.Download>
    </ImageView.Header>

    <ImageView.Stage className="riv-stage">
      <ImageView.Image />
      <ImageView.Prev>‹</ImageView.Prev>
      <ImageView.Next>›</ImageView.Next>
      <ImageView.Loading>载入中…</ImageView.Loading>
      <ImageView.Error>
        {({ retry }) => (
          <div>
            <p>无法加载这张图片</p>
            <button onClick={retry}>重试</button>
          </div>
        )}
      </ImageView.Error>

      {/* 去掉了旋转，保留缩放，顺序也改了 —— 没有哪个是必须的 */}
      <ImageView.Toolbar className="riv-toolbar">
        <ImageView.ZoomOut />
        <ImageView.ZoomIn />
        <ImageView.FitToWindow />
        <ImageView.ActualSize />
      </ImageView.Toolbar>
    </ImageView.Stage>
  </ImageView.Content>
</ImageView.Root>
```

<Aside title="只想保留大部分默认界面">
  如果你只是想开关内置选项、并不想重写，显式渲染
  `<ImageView.DefaultContent counter thumbnails />` 就行。
  自己把它放进去，正是阻止 `Root` 再补一份的方式。
</Aside>

### 用你自己的界面驱动预览器

`useViewer()` 在 `Root` 内部任意位置都能用，所以自定义控件就是一个调用 API 的按钮。

```tsx
import { useViewer } from 'react-img-view';

function ZoomReadout() {
  const viewer = useViewer();
  return <span>{Math.round(viewer.scale * 100)}%</span>;
}

function PrintButton() {
  const viewer = useViewer();
  return <button onClick={() => window.print()} disabled={viewer.status !== 'ready'}>打印</button>;
}
```

要从完全在外面的地方打开 —— 比如表格行里的「查看」按钮 —— 自己控制 `open` 和 `index`：

```tsx
const [open, setOpen] = useState(false);
const [index, setIndex] = useState(0);

<ImageView.Root
  images={files}
  open={open}
  index={index}
  onOpenChange={setOpen}
  onIndexChange={setIndex}
/>

<Button onClick={() => { setIndex(2); setOpen(true); }}>查看第 3 张</Button>
```

## 5. Extensions

对于组合方式够不着的行为 —— 拦截手势、抢占某个按键 —— 传一个 extension。
返回 `true` 表示事件已被消费，内置处理会被跳过。

```tsx
const pageWithSpace = {
  name: 'space-pages',
  onKeyDown(event, api) {
    if (event.key !== ' ') return;
    event.shiftKey ? api.prev() : api.next();
    return true; // 已处理，不要继续往下走
  },
};

<ImageView.Root images={files} extensions={[pageWithSpace]} />
```

`onGesture(phase, api)` 在指针一侧提供同样的能力，`phase` 是
`'start' | 'move' | 'end'`。任何需要**渲染**的东西都应该作为子节点放进树里 ——
extension 被刻意限制为两个钩子，而不是一套插件系统。

## 6. Labels

所有面向用户的文案都来自同一份记录。其中大多数只以 `aria-label` 的形式存在
——`errorTitle` 是默认界面里唯一还会显示成文字的一项。不传 `labels` 时，
`Root` 会按浏览器语言自动挑一个内置语言包；如果应用需要固定语言、不随访客
浏览器变化，传 `labels` 即可覆盖，逐字段合并，只覆盖其中一个不会影响其余。

```tsx
<ImageView.Root
  images={files}
  labels={{ close: '关闭', download: '下载', zoomIn: '放大' }}
/>
```

<LocalizedDemo client:load />

自定义控件应该用 `useLabels()` 读同一份文案，这样整个应用只需要翻译一处：

```tsx
import { useLabels } from 'react-img-view';

function MyClose() {
  const labels = useLabels();
  return <ImageView.Close aria-label={labels.close}>{labels.close}</ImageView.Close>;
}
```

完整的键名清单见 [`ViewerLabels`](../api-reference/#viewerlabels)。
